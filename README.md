# 🏦 SmartBank AI
### Intelligent Banking Account Recovery and Fraud Prevention System

## 📌 Project Overview
SmartBank AI is an AI-powered digital banking demo designed to simplify account recovery, improve account security, and support fraud prevention through intelligent verification.

## ✨ Key Features
- User Login and Registration
- Secure Account Recovery
- Account Unlocking Demo
- Password and PIN Reset Demo
- OTP Verification Interface
- Fraud Risk Assessment
- Admin Dashboard
- Account Activity Monitoring

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Streamlit

## 🎯 Objective
To develop a smart, secure, and user-friendly banking account recovery platform.

## ⚠️ Disclaimer
This is an educational demonstration project. It does not connect to real banking systems or process real financial transactions.
